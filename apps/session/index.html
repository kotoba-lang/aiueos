今日のシェル

ホストされた aiueos セッションです。CID は https://kotobase.net から、推論は murakumo-main 経由で、この文書のボタンがセッション過程に頼んで動かします。 `clojure -M:cloud-live check` は別の CLI で、この gate ではありません。

kotobase を読む

既定 CID は空バイト列の raw CIDv1。ゲートウェイが 200 と 0 バイトを返し、セッションがハッシュを CID と突き合わせます。


          

          

            
murakumo で推論する

            
モデル id は焼きません。alias は murakumo-main。POST はセッション過程が infer.murakumo.cloud へ送ります。

デスクトップ

          
compositor 過程が window-session-state の 2 枚を重ねます。タイトルバーは DADS（jp-go-dds）です。前面へで z-order が変わります。 virtio-gpu 2D は clojure -M:compositor gpu。IME は romaji からかなへ（clojure -M:compositor ime）。IME はかなと漢字（clojure -M:compositor kanji）。ゲスト側 IME は clojure -M:compositor guest-ime（KERNEL.ELF の Kotoba）。ゲスト側 WM は clojure -M:compositor guest-wm（KERNEL.ELF の Kotoba が z-hit）。ゲスト側 paint は clojure -M:compositor guest-paint（KERNEL.ELF が z-order で 2 枚を塗る）。ゲスト側 input は clojure -M:compositor guest-input（KERNEL.ELF が virtio-keyboard の used-ring を読む）。native compositor は leftover です。描画は kami.webgpu の clojure -M:compositor kami です。
